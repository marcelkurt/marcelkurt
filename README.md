# Content Creator Organizer

A comprehensive tool to organize your content creation routine, meetings, and personal projects.

## Features

### Dashboard
- Overview of upcoming content deadlines
- Today's meetings at a glance
- Active projects progress
- Quick stats and insights

### Content Calendar
- Schedule content across multiple platforms (YouTube, Blog, Social Media, Podcast, etc.)
- Track content status (Idea, In Progress, Review, Scheduled, Published)
- Color-coded platform identification
- Deadline tracking

### Meeting Manager
- Schedule and track meetings
- Meeting types (Client Call, Team Sync, Interview, Collaboration, Other)
- Meeting links and notes
- Duration tracking

### Personal Projects
- Create and manage projects
- Task breakdown with progress tracking
- Priority levels (Low, Medium, High, Urgent)
- Deadline management

## Getting Started

1. Open `index.html` in your web browser
2. No installation or server required
3. Data is automatically saved to your browser's local storage

## Usage

### Adding Content
1. Click "Add Content" button
2. Fill in title, platform, status, and deadline
3. Add optional description and notes
4. Click "Save"

### Scheduling Meetings
1. Navigate to "Meetings" tab
2. Click "Add Meeting"
3. Enter meeting details, date, time, and duration
4. Add meeting link and notes
5. Click "Save"

### Managing Projects
1. Go to "Projects" tab
2. Click "Add Project"
3. Enter project name and description
4. Add tasks with deadlines
5. Track progress as you complete tasks

## Data Management

- **Export**: Download all your data as a JSON file for backup
- **Import**: Restore data from a previously exported file
- **Clear**: Reset all data (use with caution)

## Browser Support

Works in all modern browsers:
- Chrome
- Firefox
- Safari
- Edge
